## 🛡️ Quick Summary of Data Practices

- **Zero Cloud Uploads:** All image compression, document conversions (Word to PDF), PDF merging, cropping, watermarking, and QR code operations are strictly performed locally on the user's mobile device.
- **No Third-Party Tracking:** ToolsBD does not sell, track, or share personal user data with third-party advertisers or data brokers.
- **Camera & Storage Permissions:** Used exclusively for real-time offline scanning and reading/saving files selected by the user.
